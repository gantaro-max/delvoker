# ゲーム企画・仕様書：Delvoker（デルヴォーカー）

本ドキュメントは、レトロスタイルなハック＆スラッシュRPG「Delvoker」の制作における根幹となる設定および機能をまとめたものである。

## 1. プロジェクト概要

| 項目 | 内容 |
| :--- | :--- |
| **タイトル** | Delvoker（デルヴォーカー） |
| **ジャンル** | 一人称視点ダンジョン探索RPG（ハック＆スラッシュ） |
| **プラットフォーム** | PC (Pyxel / Python) |
| **グラフィック** | 16色パレット / レトロドット絵 |
| **ターゲット** | Wizardryライクな硬派なRPGを好む層、アイテム収集・育成を好む層 |

## 2. 世界観・ストーリー

### 2.1 コンセプト
「底辺からの成り上がり」×「生ける大自然の迷宮」。

### 2.2 舞台：ダンジョン都市
- 一攫千金を狙う冒険者が集う、熱気と欲望に満ちた都市。
- スラム街（主人公の拠点）から、ギルドのVIPルームまで明確な階級社会が存在する。

### 2.3 主人公の背景
- スラムで育った孤児。失うものは何もなく、ただ「力」と「富」を求めて迷宮に挑む。
- 迷宮探索を通じて、自身の住居をアップグレードし、社会的な地位を上げていく。

## 3. ゲームシステム

### 3.1 ダンジョン探索
- **一人称視点（3D迷宮）：** Pyxelの描画能力を活かした、没入感の高い1st Person View。
- **成長する自然迷宮：** 階層ごとに異なる生態系（バイオーム）を持つ。

| 階層例 | バイオーム名 | 特徴 |
| :--- | :--- | :--- |
| 1-5F | 発光菌糸の森 | 青白いキノコが光る、比較的安全なエリア。 |
| 11-15F | 狂乱のジャングル | 毒を持つ植物と獰猛な獣が跋扈する。 |
| 21-25F | 水晶脈の鍾乳洞 | 氷と魔法を反射するクリスタルが広がる極寒地帯。 |

### 3.2 戦闘システム
- **ターン制コマンドバトル：** じっくりと戦略を練る形式。
- **環境ギミック：** ターン経過による花粉（毒）の蔓延や、地形の変化が戦闘に影響する。
- **部位破壊：** 特定の部位を集中攻撃することで、レアアイテムのドロップ率が向上する。

### 3.3 パーティ編成
- **臨時パーティ：** ギルドで「金」で雇う傭兵たち。最初は指示を聞かないこともある（AI行動）。
- **固定メンバー（固有NPC）：** 特定のレアアイテムを渡す、借金を肩代わりする等の条件を満たすことで「一生の相棒」となり、完全操作が可能になる。

## 4. 育成・アイテム

### 4.1 キャラクター成長
- **自動ステータスアップ：** レベルアップ時に職業に応じた値が自動で上昇。
- **ジョブ制限：** 職業ごとに成長率や装備可能品が厳格に決まっている。

### 4.2 スキル・魔法
- **魔導書システム：** レベルアップでは魔法を覚えない。ダンジョンで拾うか、街で高額な魔導書を買うことで習得する。
- **初期魔法：** 街で買えるのはごく一部のみ。強力な魔法はすべて迷宮内のドロップに依存する。

### 4.3 ハック＆スラッシュ（トレハン）
- 装備品にはランダムな性能付与（エンチャント）があり、最強の「理想個体」を求める楽しみを提供する。
- **二層エンチャント構造:** 武器への付与を「接頭辞 (Prefix)」と「接尾辞 (Suffix)」の2枠に分ける。少ないデータ量で膨大な組み合わせを生み出す設計。同種の武器でも組み合わせ次第で別物の強さになる。
- **レアリティのUI表現:** Pyxelの16色パレットと連動し、インベントリ画面のアイテム名の表示色でレア度を直感的に伝える。

| ランク | 条件 | 表示色 |
| :--- | :--- | :--- |
| Common | エンチャントなし | 白 |
| Magic | 接頭・接尾のどちらか1つ | 黄 |
| Rare | 接頭・接尾の**両方**が付与 | 橙 |
| Cursed | 呪い（マイナス効果）を含む | 紫 |

## 5. 死のペナルティとリベンジ
- **装備品のランダムロスト：** 全滅時、パーティが持っている装備の中から「1つだけ」がランダムで失われる。
- **ロスト回収（Grave System 実装済み）：** 全滅した地点に再び辿り着くことで、失ったアイテムを回収できる。守護者「Revenant」（HP 40、DEF 2、弱点 holy）との戦闘に勝利すると復元される。

### Grave クラス（`data.py`）

| フィールド | 型 | 説明 |
| :--- | :--- | :--- |
| `floor` | int | 遺品が存在するフロア番号 |
| `x` | int | 遺品のマップX座標 |
| `y` | int | 遺品のマップY座標 |
| `item` | Item | ロストしたアイテムオブジェクト |

- タイル定数: `TILE_GRAVE = 6`
- ミニマップ表示色: `COL_PINK (14)`
- `App` 側保持: `self.grave`（Grave or None）、`self.is_grave_battle`（bool）

## 6. 最終目的（クリア報酬）
- **最深部：** ダンジョンコアまたはダンジョンマスターとの決戦。
- **クリア報酬：** 「全階層への任意テレポートスキル」。これにより、クリア後の「究極のアイテム収集」が可能になる。

## 7. 技術・視覚仕様
- **Pyxel 16色：** 限られたパレットを活かし、階層ごとに色を入れ替えることで多様な環境を表現。
- **SE/BGM：** レトロなチップチューン。ダンジョンの深さに応じて重厚になっていく。
- **ダンジョン描画スタイル：** ソリッド塗りつぶし方式。壁面は深度に応じた色で塗りつぶし、ワイヤーフレーム線は使用しない（最小限のエッジ線のみ許容）。将来的には `.pyxres` リソースファイルのタイルグラフィック（`pyxel.blt()`）で壁テクスチャを表現する予定。
