# 開発タスク一覧（ロードマップ）

個人開発で挫折を防ぐため、段階的に実装を進めるタスク分解です。

## Phase 1: 基礎プロトタイプ（歩ける・戦える）
- [x] Pyxelの基本プロジェクト作成（画面サイズ、カラーパレットの初期設定）。
- [x] 一人称視点3Dダンジョンの描画テスト（ワイヤーフレーム等で、1マス進む・曲がる処理の実装）。
- [x] 基本的なターン制バトルの構築（味方1人 vs 敵1体で、攻撃してHPを減らし合う基本ロジック）。

## Phase 2: コアループの構築（潜る・戻る・成長する）
- [x] データ構造の設計（アイテムデータ、敵データ、ジョブ・ステータスクラスの作成）。
- [x] 街のメニュー画面の作成と、街⇔ダンジョンの画面遷移の実装。
- [ ] レベルアップによるステータス自動上昇ロジックの実装（ジョブごとの成長率設定）。
- [ ] アイテムインベントリ機能と、装備の着脱処理の実装。

## Phase 3: Delvoker独自の面白さの実装（ハクスラ・NPC・ペナルティ）
- [ ] 武器のランダムエンチャント（接頭辞・接尾辞の付与とステータス変化）の実装。
- [ ] パーティ複数人での戦闘対応と、臨時NPCのAI行動（勝手な行動）ロジックの実装。
- [ ] 固有NPCへの昇格条件処理と、昇格による操作権限解放の実装。
- [ ] 全滅時の「ランダムロストルーレット演出」と、アイテム消去処理の実装。
- [ ] 魔導書（アイテム）使用によるスキル習得・上書きシステムの実装。

## Phase 4: コンテンツ拡充とバランス調整
- [ ] 敵モンスターのデータ追加とドット絵の実装。
- [ ] 階層ごとの環境ギミック（毒蔓延など）や、パレット変更によるバイオーム表現の実装。
- [ ] 戦闘における「部位破壊」ギミックとレアドロップ処理の実装。
- [ ] ステータスバランス、ドロップ率、雇用費用・物価の調整。

## Phase 5: ブラッシュアップ
- [ ] 拠点アップグレード（成り上がり要素）の実装。

- [ ] SE（効果音）とBGM（レトロチップチューン）の作成・組み込み。
- [ ] 全体的なバグフィックスと最終テストプレイ。
