# 機能要件定義

## ゲーム概要

| 項目 | 内容 |
| :--- | :--- |
| **タイトル** | Delvoker（デルヴォーカー） |
| **ジャンル** | 荷物持ち（ポーター）視点のダンジョン探索RPG |
| **プラットフォーム** | PC (Pyxel / Python) |
| **グラフィック** | 16色パレット / レトロドット絵 |
| **ターゲット** | Wizardryライクな硬派なRPGを好む層、アイテム収集・育成を好む層 |

### コンセプト

「荷物持ち（ポーター）の知恵」×「生ける大自然の迷宮」。
プレイヤー自身は非力な「ポーター」となり、強力なNPCたちを管理・支援しながら、迷宮の最深部を目指します。

---

## 1. 街・拠点機能

 - **拠点（マイホーム）:** 宿泊によるHP/MP回復、アイテム倉庫、資金を消費したポーター能力の拡張（インベントリ枠、ステータス永続強化）。Warehouse・Renovate・Training の3サブメニューを提供。
- **ギルド（酒場）:** ランダムな能力・癖（AI行動）を持つ「臨時NPC」の自動生成と雇用。ギルドにて 1000G を支払うことで `NPCMember` を「固有NPC」（`is_unique = True`）へ昇格。昇格後の固有NPCは戦闘中に手動コマンド（Aid/Skill/Flee）で操作できる。
- **ショップ・闇市場:** 基本アイテムや魔導書の売買。闇市場でのランダムな魔導書の購入、全滅時にロストしたアイテムの高額買い戻し機能。

## 2. ダンジョン探索機能

- **3D視点移動:** 擬似3D（一人称視点）での前後左右の移動および方向転換処理。
- **マップ・エンカウント生成:** 階層ごとの手続き的マップ生成。歩数や確率に基づくランダムエンカウント処理。
- **環境ギミック:** ターン経過による環境ダメージ（毒など）や、特定アイテム使用によるルート開拓の判定。

## 3. 戦闘システム

- **ターン制コマンド進行:** 「援護（Aid）」「スキル」「逃げる」のコマンド選択。Aid は敵を牽制・妨害する行動で、命中時にダメージと反応ダメージを与える。素早さに基づく行動順のソートおよび実行処理。
- **パーティ編成:** プレイヤー1名 + 臨時NPC最大3名、合計最大4名（`Party.MAX_SIZE = 4`）。パーティ全員のHPが0になった場合に「全滅」と判定。
- **ポーターとしての役割:** プレイヤーは重装備を装備できず、直接攻撃よりも「援護（Aid）」・「鼓舞（Encourage）スキル」・アイテム管理に特化する非戦闘員である。
- **属性相性（三すくみ）:** fire > ice > poison > fire の三すくみ + holy 属性。ダメージ倍率計算の詳細は `3. 仕様詳細.md` 参照。
 - **装備スロット拡張:** 武器・防具に加え、「装飾品（Accessory）」スロットを追加。
- **部位破壊システム:** 敵の特定部位に対するダメージの蓄積判定。破壊成功時の部位別ドロップ抽選処理。

## 4. キャラクター育成・アイテム機能

 - **ステータス管理:** レベルアップ時に加え、新ステータス「幸運（LUK）」がクリティカル率や逃走率、アイテムドロップに影響する。
 - **職種による装備制限:** ポーター（プレイヤー）は重量武器や重鎧の装備に制限がある。
- **スキル習得:** アイテム「魔導書（Grimoire）」の使用によるスキル習得。スキルスロット最大4枠。上限到達時は最古のスキルを自動上書き（忘却）。
- **ハクスラ（アイテム生成）:** 敵ドロップ時や宝箱開封時に、武具に対してランダムなエンチャントや Genesis 級を付与する自動生成ロジック。インベントリ画面でレアリティに応じた表示色（normal / rare / epic / legend / genesis）に対応。

## 5. 状態異常システム

- **毒（Poison）:** `status_effects["poison"]` でターン数を管理。敵ターン終了時に2ダメージ。Slime が 30% 確率で付与。
- **スタン（Stun）:** `status_effects["stun"]` でターン数を管理。発動ターンはプレイヤーが行動スキップ。Skeleton が 20% 確率で付与。
- **アイコン表示:** 戦闘画面HPバー横に `[P]`（毒: 緑）・`[S]`（スタン: 黄）を表示。

## 6. マップ自動生成と探索支援

- **ランダム生成:** `Map.generate_random(width, height)` で「部屋と通路」アルゴリズムによる自動生成。ダンジョン入場のたびに異なる構造を生成。タイル種別の詳細は `3. 仕様詳細.md` 参照。
- **オートミニマップ:** 画面右下に 20×20 ピクセルの簡易マップを表示。現在地=白、探索済みフロア=グレー、階段=黄、宝箱=橙で描画。
- **宝箱ギミック:** 宝箱タイルを踏むとエンチャント付きランダムアイテムをドロップし、タイルをフロアに変換。20% でミミック出現。
- **鍵扉と泉と商人:** 各タイルインタラクションの詳細は `3. 仕様詳細.md` 参照。

## 7. ダメージポップアップ

- 通常ダメージ:白(7)、弱点ヒット:黄(10)、被ダメージ:赤(8)、回復:緑(11)。
- `add_popup(text, x, y, color)` で追加。20フレームで自然消滅し、上方向にフロート。

## 8. ステータスポイント割り振り

- レベルアップ時に `bonus_points` へ +3 加算。
- 街メニュー「Stats」より `STATE_STAT_ALLOC` 画面を開き、STR / DEF / AGI / MAG を任意に強化できる。Zキーでポイント消費、Xキーで完了。

## 9. ペナルティ処理

- **全滅・ロスト判定:** パーティ全滅時に、インベントリ・装備の中からランダムに1つを選択し強制消去する。消去時は `ITEM LOST: [Item Name]...` のログ表示と画面赤フラッシュ演出を行う。
- **ロスト品回収（遺品回収）:** 全滅時にロストしたアイテムを `Grave` オブジェクトとして保持し、同フロアの同座標に `TILE_GRAVE` を配置する。次回探索でその座標に移動すると守護者「Revenant」との戦闘が発生し、勝利するとアイテムをインベントリに復元する。

## 10. 部位破壊システム

- **部位ターゲット選択:** 敵を選んだ後、部位がある場合は「Body」および未破壊の各部位リストを表示し選択可能にする（`STATE_BATTLE_TARGET_PART`）。
- **部位HPの蓄積管理:** `Enemy.part_hps` で各部位の残HPを追跡。ダメージは本体HPと部位HP両方に同量適用。
- **破壊判定:** 部位HPが0になると `Enemy.broken_parts` に追加し、`[PART BROKEN: {name}]` をログ表示。
- **部位ドロップ:** 勝利時、破壊済み部位の `drop_flag` に対応するアイテムを 20% 確率で別枠ドロップ。

## 11. NPC深化システム

- **NPC個別装備:** インベントリからNPCへ装備を渡す機能（`STATE_INV_GIVE_NPC`）。授与後に旧装備をプレイヤーインベントリへ返却。
- **性格別スキルAI:** NPCの性格に応じて戦闘中にスキルを自律使用（reckless:40%、cowardly:80%、normal:20%）。

## 12. 永続化と解放要素

- **セーブ/ロードシステム:** ゲームを終了・再起動しても進捗を引き継ぐ永続化機能。保存対象は `player.gold`、`player.warehouse`（中身・枠数）、`player.perm_stats`、`unlocked_jobs`、`game_cleared` フラグ。JSON形式（`delvoker_save.json`）で保存。街への帰還時・Training強化直後・エンディング時に自動保存。
- **タイトル画面:** 起動時に `STATE_TITLE` を表示。セーブデータが存在する場合のみ「Continue」オプションを表示。「New Game」は完全リセット、「Continue」は保存メタを引き継いでジョブ選択へ進む。
- **ジョブ選択システム（STATE_JOB_SELECT）:** 毎回のプレイ開始時にジョブを選択できる画面。初期状態は `porter` のみ解放。B5F到達で `thief` 解放、Archdemon撃破で `mage` 解放（いずれも永続）。
- **ジョブ一覧:** `Porter`（AGI/LUK特化の非戦闘員：hp_die=8、agi_growth=0.8、luk_growth=0.7、重装備不可）。`Warrior`（基本バランス型: hp_die=12）。`Thief`（HP低め、AGI特化: hp_die=6、agi_growth=0.9）。`Mage`（HP/DEF低め、MP/MAG特化: hp_die=4、mp_die=8）。

## 13. クリア目標

- **中ボス「Dungeon Master」:** B5Fの階段を踏むと `dungeon_master` との戦闘が発生する。HP:150、全属性耐性、予兆攻撃付き。逃走は不可。撃破後はB6Fへ自動進行。
- **最終ボス「Archdemon」:** B10Fの階段を踏むと `archdemon` との最終決戦が発生する。HP:300、DEF:8、全属性耐性。逃走は不可。
- **エンディング:** Archdemon撃破後は `STATE_ENDING` へ遷移し、CONGRATULATIONS画面にキャラクター最終スタッツを表示。
- **テレポートスキル:** `grimoire_return` を使用してTeleportスキルを習得。ダンジョン内メニューからMP:10を消費して即座に街へ帰還可能。
- **コンテンツ拡張:** フロアに応じて出現敵・ドロップアイテムが変化する階層別システム（B1-3/B4-6/B7-10の三段階）。チェストから 20% 確率でミミックが出現。
