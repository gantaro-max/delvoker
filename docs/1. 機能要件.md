# 機能要件定義

企画書に基づき、プログラムとして実装すべき具体的な機能一覧です。

## 1. 街・拠点機能
* **拠点（マイホーム）管理:** 宿泊によるHP/MP回復、アイテム倉庫機能（預ける/引き出す）、資金を消費した「住居のアップグレード」（倉庫枠拡張、ステータスバフ付与など）。
* **ギルド（酒場）機能:** ランダムな能力・癖（AI行動）を持つ「臨時NPC」の自動生成と雇用。ギルドにて 1000G を支払うことで `NPCMember` を「固有NPC」（`is_unique = True`）へ昇格させる処理。昇格後の固有NPCは戦闘中に手動コマンド（Fight/Retreat）で操作できる。
* **ショップ・闇市場機能:** 基本アイテムや初期魔法の売買。闇市場での「ランダムな魔導書」の購入機能、および全滅時にロストしたアイテムの高額買い戻し機能。

## 2. ダンジョン探索機能
* **3D視点移動:** Pyxelの描画機能を活かした、擬似3D（一人称視点）での前後左右の移動、および方向転換処理。
* **マップ・エンカウント生成:** 階層（バイオーム）ごとのマップデータ読み込み。歩数や確率に基づくランダムエンカウント処理。
* **環境ギミック処理:** ターン経過による環境ダメージ（毒の蔓延など）や、特定アイテム使用によるルート開拓（ツタを斬る等）の判定。

## 3. 戦闘システム
* **ターン制コマンド進行:** 「戦う」「スキル/魔法」「アイテム」「防御」「逃げる」のコマンド選択。素早さに基づく行動順のソートおよび実行処理。
* **パーティ編成:** プレイヤー1名 + 臨時NPC最大2名、合計最大3名で構成。パーティ全員のHPが0になった場合に「全滅」と判定する。
* **NPCのAI行動（癖）:** 臨時NPCは毎ターン25%の確率で性格に基づく「勝手な行動」を取る（reckless / cowardly / selfish）。
* **属性相性（三すくみ）:** 武器属性と対象の自然属性（耐性）の相性に応じてダメージ倍率が変化する。

| 攻撃属性 | 有効な対象属性 | 倍率 |
|---|---|---|
| fire | ice 属性を持つ対象 | ×1.5 |
| ice | poison 属性を持つ対象 | ×1.5 |
| poison | fire 属性を持つ対象 | ×1.5 |
| holy | 耐性を持たないすべての対象 | ×1.2 |

* **防具エンチャント:** ドロップ防具に接頭辞（防御値変化）と接尾辞（属性耐性）がランダムに付与される。装備中の防具の属性は自動的にプレイヤーの耐性リストに追加される。
* **部位破壊システム:** 敵の特定部位に対する属性ダメージや攻撃回数の蓄積判定。破壊成功時のレアドロップフラグ付与処理。

### ダメージ計算式（Wiz風ハイブリッド方式・属性補正込み）

攻撃ダメージは以下の式で算出します。

```
基礎ダメージ = max(1, (ダイス数 × Random(1, 面数)) + 固定ボーナス + エンチャント - 対象DEF)
最終ダメージ = max(1, int(基礎ダメージ × 属性倍率))
```

**属性倍率:**
| 条件 | 倍率 |
|---|---|
| 攻撃属性が対象の Weakness に含まれる | ×1.5 |
| 攻撃属性が対象の Resistance に含まれる | ×0.5 |
| 属性なし、または対象が無関係 | ×1.0 |

| パラメータ | 説明 | 例 |
|---|---|---|
| `dice_count` | 振るダイスの個数 | 2 → 2個振って合算 |
| `dice_sides` | ダイス1個の面数（最大値） | 6 → 1〜6 |
| `static_bonus` | 武器固有の固定加算値 | +3 |
| `enchant_bonus` | 接頭辞・接尾辞が付与するボーナス | +5（Phase3で実装） |
| `DEF` | 対象のダメージ軽減値 | 2 |

**エンチャント例（ハクスラの醍醐味）:**
* `鋭い（Sharp）` → `dice_sides + 2`（同じ短剣でも最大値が上がる）
* `重厚な（Heavy）` → `static_bonus + 5`（最低保証ダメージが大幅アップ）
* `呪われた（Cursed）` → `dice_count - 1`（マイナスエンチャントもあり得る）

この方式により、同一種の武器でもエンチャントの組み合わせで性能が大きく変わり、  
ハクスラ的な「拾うたびにワクワクする」体験を実現します。

## 4. キャラクター育成・アイテム機能
* **ステータス管理:** レベルアップ時の「職業（ジョブ）」ベースの自動ステータス上昇計算処理。
* **スキル習得:** アイテム「魔導書（Grimoire）」の使用によるスキルの習得。スキルスロット最大4枠。上限到達時は最古のスキルを自動上書き（忘却）して新スキルを習得する。
* **ハクスラ（アイテム生成）:** 敵ドロップ時や宝箱開封時に、武具に対してランダムな接頭辞/接尾辞（エンチャント）とステータス補正を付与する自動生成ロジック。

### エンチャントシステム詳細設計（Phase 3実装予定）

武器への付与は「接頭辞 (Prefix)」と「接尾辞 (Suffix)」の二層構造で管理し、データは `data/enchants.json` に外部化する。

**接頭辞（Prefix）：ダメージ数値を変化させる**

| キー | 名称 | 効果 | 出現ウェイト |
| :--- | :--- | :--- | :--- |
| `sharp` | 鋭い | `dice_sides` + 2（最大ダメージ増） | 30 |
| `heavy` | 重厚な | `static_bonus` + 3（最低保証ダメージ増） | 30 |
| `master` | 達人の | `dice_count` + 1（ダイス数増＝平均値が大きく上昇） | 10 |
| `cursed` | 呪われた | `dice_count` - 1（ダイス数減、マイナスエンチャント） | 20 |

**接尾辞（Suffix）：属性・特殊効果を付与する**

| キー | 名称 | 属性 | 出現ウェイト |
| :--- | :--- | :--- | :--- |
| `fire` | +Fire | fire（植物・スライム系に特効） | 20 |
| `ice` | +Ice | ice（爬虫類系などに特効） | 20 |
| `poison` | +Poison | poison | 15 |
| `holy` | +Holy | holy（希少属性） | — |

**実装済み属性一覧（Phase 3）:** `fire`, `ice`, `poison`, `holy`
- 武器の `attribute` フィールドと敵の `weaknesses`/`resistances` リストで管理。
- プレイヤーにも `weaknesses`/`resistances` を保持し、将来の敵からの属性攻撃に対応予定。

**`data/enchants.json` データ構造**

```json
{
  "prefixes": {
    "sharp":  { "name": "鋭い",   "dice_sides_mod": 2, "static_bonus_mod": 0, "dice_count_mod":  0, "weight": 30 },
    "heavy":  { "name": "重厚な", "dice_sides_mod": 0, "static_bonus_mod": 3, "dice_count_mod":  0, "weight": 30 },
    "master": { "name": "達人の", "dice_sides_mod": 0, "static_bonus_mod": 0, "dice_count_mod":  1, "weight": 10 },
    "cursed": { "name": "呪われた","dice_sides_mod": 0, "static_bonus_mod": 0, "dice_count_mod": -1, "weight": 20 }
  },
  "suffixes": {
    "fire":   { "name": "＋炎", "attribute": "fire",   "weight": 20 },
    "ice":    { "name": "＋氷", "attribute": "ice",    "weight": 20 },
    "poison": { "name": "＋毒", "attribute": "poison", "weight": 15 }
  }
}
```

**インベントリでのレアリティ表示色（Pyxelカラー連動）**

| ランク | 条件 | 色定数 |
| :--- | :--- | :--- |
| Common | エンチャントなし | `COL_WHITE` |
| Magic | 接頭・接尾のどちらか1つ | `COL_YELLOW` |
| Rare | 接頭・接尾の**両方**が付与 | `COL_ORANGE` |
| Cursed | 呪いを含む | `COL_DARK_PURPLE` |

## 5. 状態異常システム（Phase 4実装済み）
* **毒（Poison）:** `Status.status_effects["poison"]` でターン数を管理。敵ターン終了時に2ダメージを与え、残りターン数を1減算。スライムが30%確率で付与。
* **スタン（Stun）:** `Status.status_effects["stun"]` でターン数を管理。発動ターンはプレイヤーが行動スキップし、`[Stunned] {name} cannot move!` をログ表示。スケルトンが20%確率で付与。
* **アイコン表示:** 戦闘画面HPバー横に `[P]`（毒: 緑）・`[S]`（スタン: 黄）を表示。プレイヤーおよびNPCメンバー両方に対応。

## 6. マップ自動生成と探索支援（Phase 4実装済み）
* **ランダム生成:** `Map.generate_random(width, height)` で「部屋と通路」アルゴリズムによる自動生成。ダンジョン入場のたびに異なる構造を生成。
* **タイル種別:** `TILE_FLOOR=0`, `TILE_WALL=1`, `TILE_STAIRS=2`（階段）, `TILE_CHEST=3`（宝箱）。
* **オートミニマップ:** 画面右下に20×20ピクセルの簡易マップを表示。現在地=白、探索済みフロア=グレー、階段=黄、宝箱=橙で描画。
* **宝箱ギミック:** 宝箱タイルを踏むとエンチャント付きランダムアイテムをドロップし、タイルをフロアに変換。バッグ満杯時はアイテムを失う演出メッセージを表示。
* **階段:** 踏むことで次のフロアへ進行し、新しいマップを生成。

## 7. ダメージポップアップ（Phase 4実装済み）
* 通常ダメージ: 白(7)、弱点ヒット: 黄(10)、被ダメージ: 赤(8)、回復: 緑(11)。
* `add_popup(text, x, y, color)` で追加。20フレームで自然消滅し、上方向にフロート。

## 8. ステータスポイント割り振り（Phase 4実装済み）
* レベルアップ時に `bonus_points` へ +3 加算。
* 街メニュー「Stats」より `STATE_STAT_ALLOC` 画面を開き、STR / DEF / AGI / MAG を任意に強化できる。Zキーでポイント消費、Xキーで完了。

## 9. ペナルティ処理
* **全滅・ロスト判定（実装済み）:** パーティ全滅時に、インベントリ・装備中の武器・防具の中からランダムに1つを選択し強制消去する。消去時は `ITEM LOST: [Item Name]...` のログ表示と画面赤フラッシュ演出（`flash_timer = 20`）を行う。
* **ロスト品回収（遺品回収）:** 全滅したフロアの特定座標に「遺品」オブジェクトを生成し、再到達時に戦闘イベントを経て該当アイテムを復元する処理（Phase 5以降）。

## 10. 部位破壊システム（Phase 4実装済み）
* **部位ターゲット選択:** 敵を選んだ後、部位がある場合は「Body」および未破壊の各部位リストを表示し選択可能にする（`STATE_BATTLE_TARGET_PART`）。
* **部位HPの蓄積管理:** `Enemy.part_hps` で各部位の残HPを追跡。ダメージは本体HPと部位HP両方に同量適用される。
* **破壊判定:** 部位HPが0になると `Enemy.broken_parts` に追加し、`[PART BROKEN: {name}]` をログ表示。破壊済み部位はターゲットリストから除外される。
* **部位ドロップ:** 勝利時、破壊済み部位の `drop_flag` に対応するアイテムを20%確率で本体ドロップとは別枠で抽選付与する。

## 11. NPC深化システム（Phase 5予定）
* **NPC個別装備:** NPCメンバーにプレイヤーからアイテムを渡して装備させる機能。`NPCMember.inventory` を活用し、武器・防具をNPC毎に管理する。
* **ジョブ/性格スキルAI:** NPCの性格（personality）およびジョブ（job）に応じて、戦闘中に特定スキルを自律使用するAIを実装する。例: 「reckless」 + 戦士 = 全力攻撃スキル使用、「cowardly」+ 魔法使い = バフスキル使用。
