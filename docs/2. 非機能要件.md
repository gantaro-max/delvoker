# 非機能要件定義

システムの品質、制約、開発環境に関する要件です。

## 1. 開発環境・プラットフォーム
* **開発言語/エンジン:** Python 3.11 および Pyxel エンジンを使用する。
* **対象プラットフォーム:** PC

## 2. グラフィック・サウンド制限
* **グラフィック:** Pyxelの仕様に準拠。最大解像度256×256ピクセル（想定）、16色パレットのみを使用する。パレットの動的変更によって階層ごとのバイオームを表現する。
* **サウンド:** レトロなチップチューン（Pyxel内蔵のサウンドエディタ等で作成したSE/BGM）。ダンジョンの深さに応じて重厚になっていく構成。

## 3. ユーザーインターフェース・操作方法
* **操作体系:** キーボード操作を基本とする。
  * 十字キー：移動、カーソル選択
  * Zキー：決定
  * Xキー：キャンセル
  * Cキー：メニュー開閉（想定）

## 4. セーブ・ロード機能
* **セーブのタイミング:** 街に戻ったタイミングでのオートセーブ、または拠点でのマニュアルセーブ機能。
* **データ保存形式:** 進行状況、所持アイテム、拠点状態などをJSON形式等のローカルファイルとして保存・読み込みを行う。

## 5. パフォーマンス
* **動作速度:** レトロゲーム特有の挙動を再現しつつ、Pyxelの標準FPS（30fps）を安定して維持できるよう、軽量な描画ロジックとデータ管理を心がける。
