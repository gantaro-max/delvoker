# 1. Task Overview
Phase 4の残存タスク（戦闘の高度化、マップ自動生成、成長拡張）を完遂します。
単なる機能追加に留まらず、ミニマップによる探索性の向上や、ダメージ数値の色分け・ボスの予備動作による視覚的・戦略的フィードバックの強化を盛り込み、ゲームとしての完成度を引き上げます。

# 2. Target Files
* `main.py`: 全体管理、描画統合
* `data.py`: `Status`, `Map`, `NPCMember`, `EnemyDef` クラスの拡張
* `data/enemies.json`: AIタイプおよび特殊行動データの追加
* `ui.py`: ミニマップ、ステータスアイコン、ポイント割り振りUIの新規実装

# 3. Step-by-Step Instructions

## 3.1 戦闘フィードバックと状態異常
1.  **カラーポップアップ:** `BattleManager` に `popups` リストを追加。
    *   白(7): 通常, 黄(10): 弱点, 赤(8): 被弾, 緑(11): 回復。
    *   `add_popup(text, x, y, color)` メソッドを作成。タイマーで20フレーム程度表示。
2.  **状態異常とアイコン:** `Status` クラスに `status_effects = {"poison": 0, "stun": 0}` を追加。
    *   `draw` 処理にて、HPバーの横に `[P]` (毒), `[S]` (スタン) を表示。
    *   毒はターン終了時にダメージ、スタンは行動スキップ。ログに `[Stunned] {name} cannot move!` と表示。

## 3.2 マップ自動生成と探索支援
1.  **ランダム生成:** `Map.generate_random(width, height)` を実装。
    *   「部屋と通路」アルゴリズムを採用し、`TILE_STAIRS` (階段) と `TILE_CHEST` (宝箱) を1つ以上配置。
2.  **オートミニマップ:** 画面右下に `16x16` ピクセル程度の簡易マップを表示。
    *   `Map.visited[x][y]` で歩いた場所を管理。現在地を白点、探索済みをグレー点で描画。
3.  **ギミック:** 宝箱を開ける際、レアアイテム（接頭辞/接尾辞付き）がドロップする演出を追加。

## 3.3 成長システムの拡張
1.  **Bonus Points:** `Status` に `bonus_points` プロパティを追加。LvUP時に +3 加算。
2.  **割り振りUI:** `STATE_HOME` (拠点) で `STR/DEF/AGI/MAG` を強化できる画面を実装。
    *   Zキーでポイント消費、Xキーで完了。

## 3.4 敵AIの多様化と予兆
1.  **AI行動パターン:** `enemies.json` の `ai_type` に基づき、ターゲット選択ロジックを分岐。
    *   `ranged`: AGIが高い順、`support`: HPが減っている仲間を優先。
2.  **ボスの予兆:** 強力な攻撃の1ターン前に `telegraph_message` (例: `The boss is charging power...`) を表示し、プレイヤーに防御を促す。

# 5. Constraints
* **ASCII文字のみ:** `[P]`, `[S]` 等の記号、メッセージはすべて半角英数字・記号。
* **Pyxel16色制限:** ポップアップの色はパレット(0-15)から適切に選択。
* **ミニマップサイズ:** メイン視界を遮らないよう、隅にコンパクトに配置（例: 32x32以内）。

# 6. Success Criteria
1. 戦闘中、ダメージ数値が適切な色で飛び出し、数秒で消えること。
2. 毒やスタンが正しく機能し、視覚的なアイコンが表示されること。
3. ダンジョンに入るたびに異なる構造のマップが生成され、階段で進行できること。
4. 移動に合わせてミニマップが更新され、歩いた範囲が確認できること。
5. レベルアップ後、拠点でステータスを任意に強化でき、戦闘に反映されること。
6. ボスが強力な攻撃の前に警告メッセージを出し、戦略的な防御が可能であること。
