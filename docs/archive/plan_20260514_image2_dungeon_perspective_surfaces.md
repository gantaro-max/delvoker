# Image 2.0 Request Specification: Dungeon Perspective Surfaces

## 1. Purpose

現在の3Dダンジョン表示では、天井・側面壁・床・奥の面が同系統のテクスチャで描かれるため、遠近感と面の区別が弱い。

Image 2.0へ依頼する画像は、単なる壁模様ではなく、以下を視覚的に分離できる素材にする。

- Ceiling: 天井
- Side Wall: 左右の壁
- Front Wall: 正面の壁
- Floor: 床
- Far End: 奥の暗がり・突き当たり

最終的にはPyxel上で16色・低解像度に変換されるため、写実性よりも「面の向き」「奥行き」「明暗差」「シルエットの読みやすさ」を優先する。

## 2. Current Rendering Constraints

現行実装:

- 3D描画: `ui/renderer_3d.py`
- 現在の壁テクスチャ: Bank 0 の8x8タイル
  - B1F-B2F: `(0, 64)`
  - B3F-B4F: `(8, 64)`
  - B5F以降: `(16, 64)`
- 現在は天井・床・前面壁・側面壁に同じ8x8タイルを繰り返し描画している。
- そのため、天井・床・壁・奥が同じ模様に見えやすい。

今回Image 2.0へ依頼する素材は、後続実装で以下のように分けて使う想定にする。

| Surface | 用途 | 視覚要件 |
| :--- | :--- | :--- |
| Ceiling | 画面上半分の天井 | 暗め、横方向の石組み、上に沈む印象 |
| Side Wall | 左右壁 | 奥へ流れる斜め方向、垂直な横壁として読める模様 |
| Front Wall | 正面壁 | 正面向きの垂直な石壁、斜めに流れない模様 |
| Floor | 画面下半分の床 | 斜め/奥方向の敷石、足元から奥へ向かう導線 |
| Far End | 奥の暗がり | 黒に近い、面全体が暗い突き当たり壁として読める |

補足:
- 正面にある壁は、距離が近い/中間/遠い場合でも `Front Wall` 素材を使う。
- 左右の壁は `Side Wall` 素材を使い、左壁は右壁用素材をゲーム側で左右反転して使う。
- `Far End` は正面壁のnear/mid/far差分ではなく、表示可能な奥行きの先に壁が無いとき、最奥を暗く閉じるための背景面として扱う。
- 正面壁の距離段階は、正面壁素材を増やすのではなくゲーム側の描画サイズ、位置、枠線、必要なら暗色オーバーレイで表現する。

## 4. Image Output Requirements

Image 2.0への共通出力要件:

- PNG形式。
- 正方形画像。
- 推奨サイズ: `512x512` または `1024x1024`。
- 文字、UI、キャラクター、アイテム、モンスターは入れない。
- カメラ視点は「素材」として使いやすい正面またはパターン寄りにする。
- 最終的に8x8または16x16へ縮小されるため、大きな形・明暗・方向性を優先する。
- Pyxel標準16色へ減色される前提。
- 細かすぎる石目、微細なノイズ、写真風の質感は避ける。
- 面ごとの明度差を強くする。
- 黒背景UIと混ざりすぎないよう、完全な黒だけでなく暗灰・縁取りの差を残す。
- ただしFar Endはほかの面より暗くしつつ、石の輪郭と階層色が読める明度を残す。

## 5. Surface-Specific Art Direction

### Ceiling

目的: 画面上側が「天井」として読めること。

要件:
- 全体を暗めにする。
- 石の継ぎ目は横方向を強める。
- 床よりも彩度と明度を落とす。
- 上方向に圧迫感があるデザイン。
- 水滴、ひび、垂れ下がる影などは少量なら可。

避ける:
- 床と同じ敷石パターン。
- 明るすぎるハイライト。
- 上下左右どちらにも見える無方向ノイズ。

### Side Wall

目的: 左右壁が「奥へ続く垂直な横壁」として読めること。

要件:
- 縦方向の割れ目、柱状の石組み、壁面の縁を意識する。
- 床よりも明暗の縦コントラストを強くする。
- 壁のブロック境界が8x8縮小後も残る。
- 右側の横壁を基準に、壁面上の石目やひびだけを奥へ流す。
- 左右にタイル反復しても破綻しにくい。

避ける:
- 床と同じ水平敷石。
- 過度な斜めパース。
- 細かい装飾だけで構成された模様。
- 床、天井、部屋の角、通路全体、床と壁の境界線を描くこと。

### Front Wall

目的: 正面にある壁が「突き当たりの垂直な石壁」として読めること。

正面壁について:
- 正面壁が近距離、中距離、遠距離に出る場合も同じ `Front Wall` 素材を使用する。
- near / mid / far の正面壁専用素材は作らない。
- 距離による見え方の違いは、後続実装で描画矩形の大きさ、位置、アウトライン、暗色オーバーレイで調整する。

要件:
- 正面向きの垂直な石壁として作る。
- 石の継ぎ目やひびを斜めに奥へ流さない。
- 左右反転前提ではなく、中央から見た正面壁として自然に見える。
- 正方形全体を石壁だけで埋める。
- 床、天井、部屋の角、通路全体、床と壁の境界線を描かない。

避ける:
- 右側の横壁のような斜めパース。
- 床や天井に見える水平面。
- 出口、扉、穴、通路の続きに見える強い中央暗部。

### Floor

目的: 画面下側が「床」として読め、奥方向への導線が出ること。

要件:
- 石畳・板・割れ目が奥方向へ流れる印象。
- 天井より明るめ。
- 足元側に少し強いコントラスト。
- 斜めや縦方向の線を使い、奥へ進む感じを出す。

避ける:
- 壁と同じ縦石目。
- 完全に均一なノイズ。
- 模様が細かすぎて8x8化で潰れるデザイン。

### Far End

目的: 奥の突き当たり、または闇として読めること。

位置づけ:
- `Far End` は正面壁の遠距離版ではない。
- 通路が表示可能な奥行きの先まで続いているとき、画面中央の最奥に置く暗い終端面として使う。
- 実際に正面に壁がある場合は、距離に関係なく `Front Wall` 素材を使う。

要件:
- ほかの面より明確に暗い。
- 中央だけではなく、面全体が暗い突き当たり壁として読める。
- 壁や床との境界線、部屋の角、通路全体は描かない。
- 階層ティアごとの雰囲気差を反映する。
- B3F-B4F / B5F-B10F は、B1F-B2F Far End の石壁構造、輪郭量、明暗バランスをベースに色替えして作る。
- 下層へ行くほど黒く潰すのではなく、色相、苔、ひび、赤紫の気配で階層差を出す。

避ける:
- 完全な単色黒だけ。
- 明るい壁と同じ模様。
- 出口のように見えすぎる強い光。
- 丸い穴、丸い影、スポットライト、中心だけ黒いビネット。

## 6. Biome Art Direction

### B1F-B2F: Early Stone

テーマ:
- 明るめの石造り。
- 初期階層、まだ人工的で読みやすい。
- 清潔すぎないが、過度に怖くしない。

推奨色傾向:
- light gray
- dark gray
- muted green accent
- small warm stone highlights

### B3F-B4F: Damp Moss

テーマ:
- 湿った石、苔、ひび、水染み。
- B1F-B2Fの構造と明暗バランスを保った色違いとして、緑と青の湿気感を加える。
- 床は濡れて少し反射している印象でもよい。

推奨色傾向:
- muted green
- blue gray
- moss green
- muted cyan highlights

### B5F-B10F: Cursed Depths

テーマ:
- B1F-B2Fの構造と明暗バランスを保った色違いとして、黒紫の石、呪い、骨のような筋、魔界的な深部を表現する。
- 強敵階層らしく、赤・紫・黒を少量使う。
- ただし画面全体が真っ黒にならないよう輪郭差を残す。

推奨色傾向:
- near black accents
- dark purple
- dark red
- bone gray
- mid purple gray
- small orange or pink cursed highlights

```text
深層階の最奥らしく、危険で不吉な雰囲気にしてください。ただし、画像全体を黒へ潰さないでください。

通常の壁素材と同じ明るさにしないでください。
完全な黒一色にもせず、石の面、端の輪郭、ひび、骨灰色の筋が縮小後も見える明度を残してください。
出口や扉のように見える強い光は入れないでください。
丸い穴、丸い影、スポットライト、中心だけ黒いビネットにはしないでください。
奥へ続く床や左右の壁を描かないでください。
縮小後も「最深部の暗い突き当たり壁」と分かるように、面全体の暗さ、石壁の輪郭、赤紫の気配を初期階層と同程度に残してください。
```
