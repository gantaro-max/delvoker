# Implementation Plan: Assets Pyxres Creation Specification

## 1. Task Overview

`assets.pyxres` に Delvoker で使用するモンスター32x32スプライトと、3Dダンジョン壁用8x8テクスチャを作成するための制作・実装指示書です。

主目的:
- Image Bank 0 に全モンスター画像を所定座標で配置する。
- Image Bank 0 の `V=64` 行に壁テクスチャを配置し、モンスター領域と衝突しないようにする。
- 既存コード・仕様書の壁テクスチャ参照座標を、今回の制作仕様 `(0,64)`, `(8,64)`, `(16,64)` に同期する。
- `assets.pyxres` が存在する環境では、敵スプライトと壁テクスチャが正しく表示される状態にする。

## 2. Target Files

- `/workspaces/games/assets.pyxres`: Pyxel標準エディタで作成・編集する画像リソース。
- `/workspaces/games/ui/renderer_3d.py`: 壁テクスチャの参照座標を `V=64` へ変更する。
- `/workspaces/games/data/enemies.json`: モンスター `sprite_u` / `sprite_v` が本指示書の座標と一致していることを確認する。
- `/workspaces/games/docs/3. 仕様詳細.md`: グラフィック・アセット仕様と3D壁テクスチャ仕様を最新化する。
- `/workspaces/games/docs/4. 開発タスク.md`: アセット制作タスクと完了チェックを追加する。

## 3. Asset Format

| 項目 | 指定 |
| :--- | :--- |
| ファイル名 | `assets.pyxres` |
| 配置場所 | `main.py` と同じ `/workspaces/games/` 直下 |
| 編集ツール | `pyxel edit assets.pyxres` |
| 使用イメージバンク | Bank 0 |
| 透過色 | カラーインデックス 0（黒） |
| 使用色 | Pyxel標準16色、色番号0-15のみ |

注意:
- ゲーム内表示文字列はASCIIのみだが、本ファイルは制作指示書なので日本語説明を許容する。
- スプライトの背景部分は必ず色0で塗る。
- 外縁に白・薄グレーなどの明部を少量入れ、黒背景の戦闘画面で輪郭が見えるようにする。

## 5. Dungeon Wall Texture Layout

3Dビューで使用する壁模様は Image Bank 0 の `V=64` 行に 8x8 ピクセルで描く。プログラム側でタイル状に敷き詰める。

| 座標 `(U,V)` | 対象階層 | 制作イメージ |
| :---: | :--- | :--- |
| `(0,64)` | B1F-B2F | 明るい石レンガ、洞窟の壁。 |
| `(8,64)` | B3F-B4F | 苔、湿り気、深部感のある石壁。 |
| `(16,64)` | B5F以降 | 暗く禍々しい黒い大理石、骨、魔界風の壁。 |

重要:
- 既存の `ui/renderer_3d.py` は現状 `_BIOME_TILES = [(0,0), (8,0), (16,0)]` を参照しているため、実装時に `[(0,64), (8,64), (16,64)]` へ変更する。
- `docs/3. 仕様詳細.md` の「11.3 バイオーム別タイルソース座標」も `ty=64` へ更新する。

## 6. Art Direction

- 基本色は緑(3)・濃緑(11)を含めると、既存の階層別パレットスワップが分かりやすい。
- 深層・ボス用の色替えがコード側で入るため、元絵は極端に黒へ寄せすぎない。
- 透過色0と主要輪郭色を混同しない。黒背景に溶ける場合は灰色(5/6/13)や白(7)で輪郭を補う。
- 32x32内でキャラのシルエットが読めることを優先する。細部よりも輪郭・顔・武器・翼などの記号性を重視する。
- 壁テクスチャは8x8の繰り返しで破綻しないよう、左右端・上下端が自然につながるパターンにする。

## 7. Implementation Steps

### Step 1: `assets.pyxres` 作成

1. `/workspaces/games` で `pyxel edit assets.pyxres` を実行する。
2. Imageエディタを開き、Bank 0 を選択する。
3. 4章・5章の座標に従ってスプライトと壁テクスチャを描く。
4. `Ctrl+S` で保存する。

### Step 2: 壁テクスチャ参照座標の修正

1. `ui/renderer_3d.py` の `_BIOME_TILES` を以下に変更する。

```python
_BIOME_TILES = [(0, 64), (8, 64), (16, 64)]
```

2. `_blt_tile()` は既存の8x8タイリング処理を維持する。
3. `assets_loaded = False` 時の単色フォールバックは維持する。

### Step 3: 敵スプライト座標の確認

1. `data/enemies.json` の全12体に `sprite_u` / `sprite_v` が定義されていることを確認する。
2. 本指示書4章の座標と差異があれば、`data/enemies.json` 側を本指示書に合わせる。
3. `main.py` の `pyxel.blt(..., 0)` で透過色0が使われていることを維持する。

### Step 4: ドキュメント同期

1. `docs/3. 仕様詳細.md` の「8. グラフィック・アセット仕様」に本レイアウトを反映する。
2. `docs/3. 仕様詳細.md` の「11.3 バイオーム別タイルソース座標」を `ty=64` に更新する。
3. `docs/4. 開発タスク.md` にアセット制作・確認タスクを追加する。

### Step 5: 動作確認

1. `python -B main.py` で起動する。
2. コンソールに `[WARN] assets.pyxres load failed` が出ないことを確認する。
3. 戦闘で全モンスターのスプライトが表示されることを確認する。
4. B1F-B2F、B3F-B4F、B5F以降で壁テクスチャが切り替わることを確認する。
5. `assets.pyxres` を一時的に読み込めない状態にした場合でも、フォールバック描画でクラッシュしないことを確認する。

## 8. Constraints

- **Bank固定:** すべて Bank 0 に描く。
- **透過色固定:** 背景透過はカラーインデックス0。
- **色範囲:** Pyxel色番号0-15のみ。
- **座標固定:** モンスター領域 `V=0,32` と壁テクスチャ領域 `V=64` を混在させない。
- **互換性:** `assets.pyxres` が存在しない場合のフォールバック描画を壊さない。
- **パレットリセット:** 敵描画のパレットスワップ後は既存通り `pyxel.pal()` リセットを維持する。

## 9. Success Criteria

1. `/workspaces/games/assets.pyxres` が存在し、Pyxelで読み込める。
2. Image Bank 0 の指定座標に全12体の32x32モンスタースプライトが配置されている。
3. Image Bank 0 の `(0,64)`, `(8,64)`, `(16,64)` に8x8壁テクスチャが配置されている。
4. `ui/renderer_3d.py` が壁テクスチャを `V=64` から参照している。
5. `data/enemies.json` の `sprite_u` / `sprite_v` が本指示書と一致している。
6. `python -B main.py` 起動時に `assets.pyxres` ロード警告が出ない。
7. 戦闘画面で敵スプライトが表示され、黒背景でも輪郭を視認できる。
8. 3Dダンジョンの壁が階層に応じて異なる8x8テクスチャで描画される。
9. `docs/3. 仕様詳細.md` と `docs/4. 開発タスク.md` が最終仕様と同期している。
