    [タイトル画面]
       ├─> [街メニュー画面]（ハブ画面）
       │      ├─> 拠点（宿泊/倉庫/改築）
       │      ├─> ギルド（編成/雇用）

## 2. 主要画面のUI構成案

### ダンジョン探索画面
* **上部・中央:** 一人称視点の迷宮描画（階層が深くなるにつれ暗闇表現を強める）。
* **下部:** パーティメンバーの簡易ステータス（顔グラフィックアイコン、HP/MPバー）。※固有NPC昇格時に汎用アイコンから固有アイコンに変化。
* **右上:** 現在の階層表示。

### 戦闘画面
* **中央:** 敵のドット絵（部位破壊が可能な箇所は色を変えるなどで視覚的に強調）。
* **下部:** コマンド選択ウィンドウ、行動テキストログ。
* **各種演出:** ダメージ時の画面シェイク、フラッシュなど、Pyxelの機能を活かした打撃感の表現。

### ロスト判定演出画面（全滅時）
* **中央:** 装備アイコンがルーレットのように高速回転し、1つ選ばれて砕け散る（または奪われる）アニメーション演出。
