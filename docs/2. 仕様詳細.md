# 仕様詳細

実装済み機能の詳細仕様をまとめたドキュメントです。

---

## 1. パーティ編成システム

### 1.1 構成

| 役割 | クラス | 最大人数 |
| :--- | :--- | :---: |
| プレイヤー | `Player` (extends `Status`) | 1 |
| 臨時NPC | `NPCMember` (extends `Status`) | 2 |
| **パーティ合計** | `Party` | **3** |

### 1.2 Party クラス仕様 (`data.py`)

| メンバー / プロパティ | 型 | 説明 |
| :--- | :--- | :--- |
| `members` | `list[Status]` | index 0 = プレイヤー、以降 NPC |
| `add(member)` | `bool` | 満員時 `False`、追加成功時 `True` |
| `is_wiped_out` | `bool` | 全員 HP ≤ 0 なら `True`（全滅判定） |
| `alive` | `list[Status]` | HP > 0 のメンバー一覧 |
| `MAX_SIZE` | `int` | `3`（定数） |

### 1.3 NPCMember クラス仕様 (`data.py`)

```
NPCMember(job_key, name, personality)
```

| フィールド | 型 | 有効値 / 説明 |
| :--- | :--- | :--- |
| `personality` | `str` | `"normal"` \| `"reckless"` \| `"cowardly"` \| `"selfish"` |
| `inventory` | `list` | アイテム所持（現在は空） |
| `is_unique` | `bool` | `False`（デフォルト）/ `True` = 固有NPC（手動操作可能） |

### 1.4 固有NPC昇格システム

- **場所:** ギルド画面（街メニュー > Guild）
- **費用:** `PROMOTION_COST = 1000G`
- **効果:** `npc.is_unique = True` に設定
- **戦闘での変化:** 昇格済み固有NPCは `STATE_BATTLE_NPC_CMD` でコマンド選択（Fight / Retreat）が可能になる。未昇格NPCは引き続きAI自動行動。

## 2. NPC AI 行動システム

### 2.1 発動条件

- 戦闘中、プレイヤーの行動後に各 NPC メンバーが順番に行動する。
- 各 NPC ターンに `random() < 0.25`（**25%確率**）で AI 行動（暴走）が発動する。

### 2.2 性格別 AI 行動

| 性格 | キー | AI 行動（暴走時） | 通常行動 |
| :--- | :--- | :--- | :--- |
| 普通 | `normal` | 通常攻撃（暴走なし） | 通常攻撃 |
| 無謀 | `reckless` | 命令を無視して**追加攻撃**（ダメージ計算あり） | 通常攻撃 |
| 臆病 | `cowardly` | 怯えて**行動スキップ**（ダメージなし） | 通常攻撃 |
| 利己的 | `selfish` | 自身の傷に集中し**行動スキップ** | 通常攻撃 |

### 2.3 ログメッセージ規則（ASCII制約）

- AI 行動発動時: `{name} acts on their own!`
- 無謀の追加攻撃: `[Reckless] {name} attacks wildly! {enemy}: -{dmg} HP!`
- 臆病スキップ: `[Cowardly] {name} hesitates and does nothing!`
- 利己的スキップ: `[Selfish] {name} tends to their own wounds! (skipped)`
- 通常攻撃: `{name} attacks! {enemy}: -{dmg} HP!`

## 3. 属性相性システム（三すくみ）

### 3.1 ATTR_AFFINITY 定数 (`data.py`)

```python
ATTR_AFFINITY = {"fire": "ice", "ice": "poison", "poison": "fire"}
```

`ATTR_AFFINITY[A] = B` は「A は B 属性を持つ対象に特効」を意味する。

### 3.2 ダメージ計算優先順位

| 優先順位 | 条件 | 倍率 |
| :--- | :--- | :---: |
| 1 | `weapon.attribute` in `target.weaknesses` | ×1.5 |
| 2 | `weapon.attribute` in `target.resistances` | ×0.5 |
| 3 | `ATTR_AFFINITY[weapon.attribute]` in `target.resistances` | ×1.5 |
| 4 | `weapon.attribute == "holy"` (耐性なし) | ×1.2 |
| 5 | その他 | ×1.0 |

### 3.3 防具エンチャントシステム

#### EnchantedArmor クラス (`data.py`)

| フィールド | 型 | 説明 |
| :--- | :--- | :--- |
| `prefix` | `dict \| None` | 接頭辞（`def_bonus_mod` を持つ） |
| `suffix` | `dict \| None` | 接尾辞（`attribute` を持つ） |
| `attribute` | `str \| None` | 付与属性（装備者の耐性に自動追加） |
| `rarity` | `str` | `"magic"` or `"common"` |

#### 防具エンチャントテーブル (`enchants.json`)

**接頭辞（armor_prefixes）:**

| キー | 名称 | 効果 | ウェイト |
| :--- | :--- | :--- | :---: |
| `sturdy` | Sturdy | `def_bonus` +2 | 30 |
| `light` | Light | `def_bonus` -1 | 20 |

**接尾辞（armor_suffixes）:**

| キー | 名称 | 耐性属性 | ウェイト |
| :--- | :--- | :--- | :---: |
| `of_heat` | Heat | fire | 20 |
| `of_cold` | Cold | ice | 20 |
| `of_venom` | Venom | poison | 15 |

#### Status.resistances プロパティ (`data.py`)

`Status.resistances` はダイナミックプロパティ。  
`self._resistances`（基本耐性リスト）に `self.armor.attribute`（装備防具の属性）を自動的に含めて返す。

## 4. スキルシステム

### 4.1 Skill クラス仕様 (`data.py`)

```python
Skill(name, mp_cost, effect_type, power)
```

| フィールド | 型 | 説明 |
| :--- | :--- | :--- |
| `name` | `str` | スキル名（ASCII） |
| `mp_cost` | `int` | 発動に必要なMP |
| `effect_type` | `str` | `"attack"` \| `"heal"` |
| `power` | `int` | ダメージ/回復量の基礎値 |

### 4.2 GrimoireItem 仕様 (`data.py` / `items.json`)

| フィールド | 型 | 説明 |
| :--- | :--- | :--- |
| `skill_name` | `str` | 習得するスキル名 |
| `mp_cost` | `int` | スキルのMP消費 |
| `effect_type` | `str` | スキルのタイプ |
| `power` | `int` | スキルの威力 |

### 4.3 スキル習得ルール

- `Status.skills` の最大スロット数: `MAX_SKILLS = 4`
- 魔導書（Grimoire）使用時: `Skill` を生成して `skills` リストへ追加
- スロット満杯時: `skills.pop(0)`（最古を削除）して新スキルを末尾に追加
- 戦闘コマンド画面: 習得済みスキル一覧を `Skill:` ラベルとともに表示

## 5. 全滅・敗北処理

- **全滅条件:** `party.is_wiped_out` が `True`（全パーティメンバー HP ≤ 0）
- **現在の敵ターゲット:** 敵は常にプレイヤーを攻撃する（将来的に全メンバーをターゲットに拡張予定）
- **敗北後の処理:** 全パーティメンバーの HP / MP を最大値に回復し、街へ強制帰還する
- **ロストルーレット演出:**
  - 対象: `player.inventory` の各アイテム + 装備中の武器 + 装備中の防具
  - 選択: ランダムに1つを選択して消去
  - 演出: `ITEM LOST: [Item Name]...` のログ出力 + `flash_timer = 20`（赤フラッシュ20フレーム）

## 6. 将来的な拡張（Phase 4以降）

### 4.1 高度な戦闘
- **スキル(Skill/Spell)**: MPを消費して発動。`data.py` の `Status` に MP 管理を統合済み。
- **状態異常**: `Poison`, `Stun` 等の状態フラグを `Status` に追加予定。

### 4.2 マップ自動生成
- **アルゴリズム**: ルーム＆コリドー方式を想定。
- **ギミック**: 階段 (`Stairs`) による階層移動と、宝箱 (`Chest`) によるアイテムドロップ。

### 4.3 成長システム
- **ステータス割り振り**: レベルアップ時にポイントを付与し、プレイヤーが STR/DEF/AGI を強化できる仕組み。
