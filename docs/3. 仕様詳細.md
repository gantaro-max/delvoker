# 仕様詳細

本ドキュメントはDelvokerの実装仕様をシステム別にまとめた技術リファレンスです。
計算式、データ構造、アルゴリズムをここに一元管理します。

---

## 1. コアシステム

### 1.1 パーティ構成

| 役割 | クラス | 最大人数 |
| :--- | :--- | :---: |
| プレイヤー | `Player` (extends `Status`) | 1 |
| 臨時NPC | `NPCMember` (extends `Status`) | 2 |
| **パーティ合計** | `Party` | **3** |

### 1.2 Party クラス仕様 (`data.py`)

| メンバー / プロパティ | 型 | 説明 |
| :--- | :--- | :--- |
| `members` | `list[Status]` | index 0 = プレイヤー、以降 NPC |
| `add(member)` | `bool` | 満員時 `False`、追加成功時 `True` |
| `is_wiped_out` | `bool` | 全員 HP ≤ 0 なら `True`（全滅判定） |
| `alive` | `list[Status]` | HP > 0 のメンバー一覧 |
| `fallen` | `list[Status]` | HP ≤ 0 のメンバー一覧（死亡メンバー） |
| `MAX_SIZE` | `int` | `3`（定数） |

### 1.3 NPCMember クラス仕様 (`data.py`)

```
NPCMember(job_key, name, personality)
```

| フィールド | 型 | 有効値 / 説明 |
| :--- | :--- | :--- |
| `personality` | `str` | `"normal"` \| `"reckless"` \| `"cowardly"` \| `"selfish"` |
| `inventory` | `list` | アイテム所持 |
| `is_unique` | `bool` | `False`（デフォルト）/ `True` = 固有NPC（手動操作可能） |

### 1.4 固有NPC昇格システム

- **場所:** ギルド画面（街メニュー > Guild）
- **費用:** `PROMOTION_COST = 1000G`
- **効果:** `npc.is_unique = True` に設定
- **戦闘での変化:** 昇格済み固有NPCは `STATE_BATTLE_NPC_CMD` でコマンド選択（Fight / Retreat）が可能になる。未昇格NPCは引き続きAI自動行動。

### 1.5 ステータス割り振りシステム

- `Status.bonus_points`: レベルアップ1回につき +3 加算。
- 消費: 任意のステータスを +1 するたびに -1。
- 対象ステータス: STR / DEF / AGI / MAG。

### 1.6 永続化（セーブデータ）

- **保存形式:** JSON (`delvoker_save.json`)
- **保存タイミング:** 街帰還時、Training強化時、エンディング到達時
- **保存対象:** 所持金、倉庫（アイテム・容量）、永続強化ステータス、解放済みジョブ、クリアフラグ
- **担当モジュール:** `systems/persistence.py`（`save_game` / `load_game`）

## 2. 戦闘システム

### 2.1 ダメージ計算式（Wiz風ハイブリッド方式）

```
基礎ダメージ = max(1, (dice_count × Random(1, dice_sides)) + static_bonus + enchant_bonus - target.DEF)
最終ダメージ = max(1, int(基礎ダメージ × 属性倍率))
```

| パラメータ | 説明 | 例 |
|---|---|---|
| `dice_count` | 振るダイスの個数 | 2 |
| `dice_sides` | ダイス1個の面数（最大値） | 6 |
| `static_bonus` | 武器固有の固定加算値 | +3 |
| `enchant_bonus` | 接頭辞・接尾辞が付与するボーナス | +5 |
| `DEF` | 対象のダメージ軽減値 | 2 |

### 2.2 属性倍率（優先順位順）

| 優先順位 | 条件 | 倍率 |
| :--- | :--- | :---: |
| 1 | `weapon.attribute` in `target.weaknesses` | ×1.5 |
| 2 | `weapon.attribute` in `target.resistances` | ×0.5 |
| 3 | `ATTR_AFFINITY[weapon.attribute]` in `target.resistances` | ×1.5 |
| 4 | `weapon.attribute == "holy"` かつ耐性なし | ×1.2 |
| 5 | その他 | ×1.0 |

### 2.3 敵 AI 行動タイプ

| ai_type | ターゲット選択ロジック |
| :--- | :--- |
| `"normal"` | `party.alive[0]`（プレイヤー優先） |
| `"ranged"` | AGI が最高の生存メンバーを攻撃 |
| `"support"` | HP が最低の生存メンバーを攻撃 |

### 2.4 ボス予兆（telegraph）

- 設定されているボス敵は 30% の確率で強力攻撃の1ターン前に警告メッセージを表示。
- 次ターンは 2倍ダメージの攻撃（`[POWER]`）を実行。

### 2.5 NPC AI 自動行動ロジック

| 性格 | キー | スキル使用条件 | スキル発動確率 | 通常行動 |
| :--- | :--- | :--- | :---: | :--- |
| 無謀 | `reckless` | 攻撃スキル所持 + MP 足りる | **40%** | 通常攻撃 |
| 臆病 | `cowardly` | 回復スキル所持 + MP 足りる + 味方 HP 50%以下 | **80%** | 行動スキップ |
| 普通 / 利己的 | `normal` / `selfish` | スキル所持 + MP 足りる | **20%** | 通常攻撃 |

**スキル選択ロジック:**
- `reckless`: `effect_type == "attack"` のスキルのみ対象。ランダムに1つ選択。
- `cowardly`: `effect_type == "heal"` のスキルのみ対象。HP 最低の味方を回復。
- `normal`: 攻撃 or 回復スキルをランダム選択。回復時は HP 最低の生存メンバーを対象。

**スキルダメージ / 回復量:** `max(1, skill.power + npc.mag)`

### 2.6 ダメージポップアップ

| 種別 | 色 |
| :--- | :--- |
| 通常ダメージ | 白 (7) |
| 弱点ヒット | 黄 (10) |
| 被ダメージ | 赤 (8) |
| 回復 | 緑 (11) |

### 2.7 状態異常

| 異常 | フィールド | 効果 | 付与例 |
| :--- | :--- | :--- | :--- |
| 毒 | `status_effects["poison"]` | 敵ターン終了時に2ダメージ、残ターン-1 | Slime (30%) |
| スタン | `status_effects["stun"]` | プレイヤーの行動を1ターンスキップ | Skeleton (20%) |

戦闘画面HPバー横に `[P]`（毒: 緑）・`[S]`（スタン: 黄）を表示。

## 3. 装備・属性システム

### 3.1 ATTR_AFFINITY 定数 (`data.py`)

```python
ATTR_AFFINITY = {"fire": "ice", "ice": "poison", "poison": "fire"}
```

`ATTR_AFFINITY[A] = B` は「A は B 属性を持つ対象に特効」を意味する（三すくみ）。

### 3.2 武器エンチャント

データ定義: `data/enchants.json`

**接頭辞（Prefix）：ダメージ数値を変化させる**

| キー | 名称 | 効果 | ウェイト |
| :--- | :--- | :--- | :---: |
| `sharp` | Sharp | `dice_sides` + 2 | 30 |
| `heavy` | Heavy | `static_bonus` + 3 | 30 |
| `master` | Master | `dice_count` + 1 | 10 |
| `cursed` | Cursed | `dice_count` - 1 | 20 |

**接尾辞（Suffix）：属性を付与する**

| キー | 名称 | 属性 | ウェイト |
| :--- | :--- | :--- | :---: |
| `fire` | +Fire | fire | 20 |
| `ice` | +Ice | ice | 20 |
| `poison` | +Poison | poison | 15 |

**レアリティ色分け:**

| ランク | 条件 | 色定数 |
| :--- | :--- | :--- |
| Common | エンチャントなし | `COL_WHITE` (7) |
| Magic | 接頭・接尾のどちらか1つ | `COL_YELLOW` (10) |
| Rare | 接頭・接尾の両方が付与 | `COL_ORANGE` (9) |
| Cursed | 呪いを含む | `COL_DARK_PURPLE` (2) |

### 3.3 防具エンチャントシステム

#### EnchantedArmor クラス (`data.py`)

| フィールド | 型 | 説明 |
| :--- | :--- | :--- |
| `prefix` | `dict \| None` | 接頭辞（`def_bonus_mod` を持つ） |
| `suffix` | `dict \| None` | 接尾辞（`attribute` を持つ） |
| `attribute` | `str \| None` | 付与属性（装備者の耐性に自動追加） |
| `rarity` | `str` | `"magic"` or `"common"` |

**接頭辞（armor_prefixes）:**

| キー | 名称 | 効果 | ウェイト |
| :--- | :--- | :--- | :---: |
| `sturdy` | Sturdy | `def_bonus` +2 | 30 |
| `light` | Light | `def_bonus` -1 | 20 |

**接尾辞（armor_suffixes）:**

| キー | 名称 | 耐性属性 | ウェイト |
| :--- | :--- | :--- | :---: |
| `of_heat` | Heat | fire | 20 |
| `of_cold` | Cold | ice | 20 |
| `of_venom` | Venom | poison | 15 |

#### Status.resistances プロパティ (`data.py`)

`Status.resistances` はダイナミックプロパティ。
`self._resistances`（基本耐性リスト）に `self.armor.attribute`（装備防具の属性）を自動的に含めて返す。

## 4. スキルシステム

### 4.1 Skill クラス仕様 (`data.py`)

```python
Skill(name, mp_cost, effect_type, power)
```

| フィールド | 型 | 説明 |
| :--- | :--- | :--- |
| `name` | `str` | スキル名（ASCII） |
| `mp_cost` | `int` | 発動に必要なMP |
| `effect_type` | `str` | `"attack"` \| `"heal"` \| `"utility"` |
| `power` | `int` | ダメージ/回復量の基礎値 |
| `is_utility` | `bool` | ユーティリティスキルフラグ（Teleport等） |

### 4.2 GrimoireItem 仕様 (`data.py` / `items.json`)

| フィールド | 型 | 説明 |
| :--- | :--- | :--- |
| `skill_name` | `str` | 習得するスキル名 |
| `mp_cost` | `int` | スキルのMP消費 |
| `effect_type` | `str` | スキルのタイプ |
| `power` | `int` | スキルの威力 |

### 4.3 スキル習得ルール

- `Status.skills` の最大スロット数: `MAX_SKILLS = 4`
- 魔導書（Grimoire）使用時: `Skill` を生成して `skills` リストへ追加
- スロット満杯時: `skills.pop(0)`（最古を削除）して新スキルを末尾に追加

## 5. 探索・マップシステム

### 5.1 Map クラス仕様 (`logic/map_generator.py`)

| メソッド / プロパティ | 説明 |
| :--- | :--- |
| `generate_random(width=20, height=20)` | 部屋と通路アルゴリズムでランダムマップを生成 |
| `is_wall(x, y)` | 壁判定（範囲外も True） |
| `tile_at(x, y)` | タイル種別を返す（範囲外は TILE_WALL） |
| `visit(x, y)` | `visited[y][x] = True` に設定 |
| `set_tile(x, y, tile)` | タイル書き換え（宝箱開封後の FLOOR 化に使用） |
| `start_x, start_y` | 最初の部屋の中心座標 |

### 5.2 生成アルゴリズム概要

1. 全タイルを `TILE_WALL` で初期化
2. 25 回ランダムに部屋を試行配置（重複チェックあり）
3. 隣接する部屋の中心を水平→垂直の通路で接続
4. 最後の部屋の中心に `TILE_STAIRS` を配置
5. 中間の部屋に `TILE_CHEST` / `TILE_FOUNTAIN`（50%）/ `TILE_MERCHANT`（B3F以降 20%）を確率配置
6. 通路チョークポイントを検出し、最大2か所に `TILE_LOCKED_DOOR` を 30% 確率で配置
7. 鍵扉が存在する場合、`rooms[1]` に `TILE_CHEST`（key_chest_pos）を追加して `dungeon_key` を保証

### 5.3 タイル種別一覧

| 名称 | 定数 | 値 | ミニマップ色 | 効果 |
| :--- | :--- | :---: | :---: | :--- |
| 床 | `TILE_FLOOR` | 0 | グレー (5) | 通常移動 |
| 壁 | `TILE_WALL` | 1 | — | 移動不可 |
| 階段 | `TILE_STAIRS` | 2 | 黄 (10) | 次の階層へ進行 |
| 宝箱 | `TILE_CHEST` | 3 | 橙 (9) | アイテム入手。20%でミミック |
| 棘トラップ | `TILE_TRAP_SPIKE` | 4 | グレー (5) | 5〜10 ランダムダメージ |
| 毒針トラップ | `TILE_TRAP_POISON` | 5 | グレー (5) | 毒 3 ターン付与 |
| 遺品 | `TILE_GRAVE` | 6 | ピンク (14) | 守護者を倒してロストアイテム回収 |
| 鍵扉 | `TILE_LOCKED_DOOR` | 7 | インディゴ (13) | Dungeon Key で開錠 → TILE_FLOOR に変換 |
| 泉 | `TILE_FOUNTAIN` | 8 | 青 (12) | 70%で30%回復、20%で空振り、10%で毒。使用後 FLOOR 化 |
| 商人 | `TILE_MERCHANT` | 9 | 緑 (11) | 割高価格で貴重品を販売。使用後 FLOOR 化 |

### 5.4 部位破壊システム

- 戦闘中に本体とは別に部位をターゲット可能（`STATE_BATTLE_TARGET_PART`）。
- `Enemy.part_hps` で各部位の残HPを追跡。ダメージは本体HPと部位HP両方に同量適用。
- 部位HPが0になると `Enemy.broken_parts` に追加し、`[PART BROKEN: {name}]` をログ表示。
- 勝利時、破壊済み部位の `drop_flag` に対応するアイテムを 20% 確率で別枠ドロップ。

### 5.5 Grave クラス（遺品回収）(`data.py`)

| フィールド | 型 | 説明 |
| :--- | :--- | :--- |
| `floor` | `int` | 遺品が存在するフロア番号 |
| `x` | `int` | 遺品のマップX座標 |
| `y` | `int` | 遺品のマップY座標 |
| `item` | `Item` | ロストしたアイテムオブジェクト |

全滅時に `TILE_GRAVE` を配置。その座標に移動すると守護者 `revenant`（HP:40, DEF:2, 弱点:holy）との戦闘が発生し、勝利でアイテムを復元。

## 6. 街・拠点システム

### 6.1 復活サービス（`STATE_REVIVE = 13`）

| 項目 | 内容 |
| :--- | :--- |
| 費用計算 | `対象メンバーのレベル × 100 ゴールド` |
| 費用表示色 | `COL_YELLOW`（支払い可能）/ `COL_DARK_GRAY`（不足） |
| 復活効果 | 対象メンバーの HP・MP を最大値に全回復 |

### 6.2 NPC への装備授与 (`STATE_INV_GIVE_NPC = 14`)

1. アクションメニューで「Give to NPC」選択 → NPC 選択画面へ遷移
2. 対象 NPC の現在装備は自動的にプレイヤーのインベントリへ返却
3. 授与アイテムはプレイヤーのインベントリから削除、NPC の装備スロットに設定
4. NPC の `total_def`（= `def_ + armor.def_bonus`）がリアルタイムに更新される

### 6.3 拠点（Home）システム (`STATE_HOME = 15`)

#### Warehouse（倉庫）

| 変数 | 型 | 説明 |
| :--- | :--- | :--- |
| `Player.warehouse` | `list[Item]` | 倉庫保管アイテムリスト |
| `Player.warehouse_max` | `int` | 倉庫最大容量（初期値 10） |

左右キーで BAG/STORAGE を切り替え、上下キーで選択、Z で移動。

#### Renovate（倉庫拡張）費用

| 段階 | 費用 | 拡張後容量 |
| :---: | ---: | :---: |
| 1 | 500G | 15 |
| 2 | 1000G | 20 |
| 3 | 2000G | 25 |
| 4 | 4000G | 30 |
| 5 | 8000G | 35 |

現在段階 = `(warehouse_max - 10) // 5`。上限 35（5段階）。

#### Training（永続ステータス強化）費用

| 対象 | 効果 | 費用計算 |
| :--- | :--- | :--- |
| `perm_stats["str"]` | 攻撃ダメージに加算（`_player_attack` 内） | `(現在値+1) × 1000G` |
| `perm_stats["def"]` | `Player.total_def` に加算 | `(現在値+1) × 1000G` |
| `perm_stats["mag"]` | スキル実装時に反映予定 | `(現在値+1) × 1000G` |

費用は上限なし（ゴールドが許す限り何度でも強化可能）。
